# Mandatory MySQL implementation audit

This package is a **design and reference DDL**, not executed migrations. Only MySQL SQL is delivered, but DDL has not been tested on live MySQL 8.4. Its 80 logical tables and deferred FKs need integration testing and potential repair. There is a known semantic conflict in the original sources: `outbox_events` was defined twice with different column contracts; the schema retains the first definition, so developer must explicitly reconcile publishing and billing outbox producers. MySQL partial indexes have been converted to nonpartial indexes; performance must be measured. Database CHECK and application invariants must be audited, including track/entity tenancy, nullability, identity/swap guards, quota accounting, row ownership and rights.

**DO NOT** run migrations on existing `sfbhenfezi_vie` database. Confirm hosting product/version via `SELECT VERSION()` and `SELECT @@version_comment`, account privileges, transaction isolation and backed-up restore steps; MariaDB is not assumed to match MySQL 8.4. If the shared host cannot run 8.4, provision separate compatible MySQL managed service and connect backend securely, rather than silently changing syntax.

**High-value release gates:** cross-tenant denial and private S3 object access; real 22-player sample evidence and off-ball visible tracking quality; re-ID/occlusion failures not labeled confirmed; pixel/timestamp contract checks; signed rights decisions; clip RED blocking; actual MP4 encode/probe and spotlit frame diff; model licensing and accuracy baselines; webhook signature verification and idempotent quotas; disaster recovery drills; accessibility and mobile UI tests.
